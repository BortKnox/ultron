# Ultron visual captures

These images show the **standalone neural gyro orb design preview**, not the currently released or integrated desktop interface.

## Source

Captured on 12 November 2026, Australia/Sydney time, from [the interactive preview](https://htmlpreview.github.io/?https://github.com/BortKnox/ultron/blob/share/orb-mockup/docs/orb-preview/index.html). The source lives on the `share/orb-mockup` branch at `docs/orb-preview/index.html`.

Each image is a real rendered canvas frame, captured after selecting its named state and allowing the transition to settle. Images retain the full square canvas, with the preview's near-black background, and are stored as 600 × 600 WebP assets to keep README loading reasonable. No generated artwork, UI reconstruction or labels have been added.

The eight functional captures are Dormant, Ready, Listening, Thinking, Acting, Speaking, Awaiting permission and Fault warning. The four expression captures are Cold Composure, Dry Amusement, Rising Irritation and Controlled Fury. Static frames cannot convey the differences in speed, pulsing and motion; use the interactive preview for those.

## Keeping previews current

When the visual design changes, capture a clean image before closing the preview or app. Save it here with a descriptive filename, update the relevant README image, and record the source, date and whether it shows an integrated feature or a mockup. For desktop screenshots, remove API keys, personal text and other sensitive information before committing.

Keep new captures distinct from `../preview.png`. That file was introduced by the upstream Atlas project in commit `c63ca2d` and is retained as a historical reference; it does not demonstrate Ultron's current interface.
